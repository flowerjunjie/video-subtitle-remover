一 系统架构 · 6层解耦 + 4模式切换
Step 1
音频提取层（ffmpeg + PCM 48kHz/16kHz 双轨）
原始音轨从视频流分离 → 中文字幕对应中文音频轨道 → 楚音频与字幕时间轴对齐（楚音频用于TTS参考）
备选：audio-separator 分离人声用于TTS参考；视频解码 ffprobe 时长校验；文件大小超限拦截
Step 2
Whisper Large-v3 语音识别（1300M参数 · 1300层）
中文音频(16kHz mono) → 声学特征提取(80dim fbank) → Transformer(32层 attention) → 带时间戳segments
防御点：空结果拦截（静音/损坏音频）；_loaded_models 单例缓存；download_root=MODEL_DIR 避免重复下载
Step 3
翻译层（GPT-4o / DeepSeek-chat 双引擎 · 分段并行）
每segment独立调用API → 单段失败隔离(try-except) → 空结果校验(en_text.strip())
config.json model字段动态切换；API调用无OOM风险（短文本分治）
Step 4
TTS配音生成 · 四引擎级联容错
ElevenLabs（明星克隆，$0.03/字符）→ 失败切 Edge  |  Edge-TTS（AriaNeural，免费）→ 失败切 gTTS  |  gTTS（Google，备用）→ 失败抛异常  |  MOSS-TTS-Nano ONNX（0.1B，CPU推理，首次自动下载~200MB）
Windows兼容：asyncio.set_event_loop_policy(WindowsSelectorEventLoopPolicy())
临时文件：NamedTemporaryFile(delete=False) + finally手动清理；4处临时文件路径 finally统一回收
Step 5
字幕文件生成（SRT 1.1格式）
有时间轴：Whisper segments → format_srt_time() → 带时间轴SRT
无时间轴：ffprobe duration fallback → 单段字幕
防御：零duration(end <= start → end = start + 1)；UTF-8 BOM兼容播放器；空字幕段append("")保持对齐
Step 6
视频合成层 · 4模式切换（FFmpeg / Wav2Lip / DeepLiveCam / LongCat）
FFmpeg（默认）：ffmpeg -i video -i audio -c:v copy -c:a aac 无损合成，实时完成
Wav2Lip：口型同步，依赖inswapper_128_fp16.onnx + wav2lip.pth，显存~8GB，缺陷：口型精度不如Whisper-Large
DeepLiveCam：换脸+口型，execution_providers CPU/CUDA/ROCm三选一，缺陷：换脸后角色一致性弱
LongCat-Video-Avatar（全生成·GPU专属·13.6B参数）： resolution(480/720) / num_segments / audio_guidance_scale(3.0) / use_distill(8步蒸馏) / model_type(avatar-v1.5/v1.0)
INT8量化：load_quantized_dit() 20GB→~10GB（目标）；蒸馏加速：25步→8步（3倍速）
分辨率：480p(480×832) / 720p(768×1280)；多片段：OOM风险 需GPU监控
