Gradio 6.x hash_file() IsADirectoryError 修复 ● 已修复 · 待部署验证
问题：Gradio 6.x File 组件 type="filepath" 模式下，hash_file() 接收目录路径 '/root' 而非文件路径，导致 IsADirectoryError
根因：Gradio 6.x 内部 File 处理逻辑变更，filepath 类型传入了临时目录路径
修复方案：① type="filepath" → type="binary" ② 增加 bytes→临时文件转换逻辑
影响范围：video_input.change 事件链、process_video()、process_with_config() 三个入口
